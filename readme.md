# Mini-site COURS SIO WEB (AP2 - BTS SIO SISR)

Mini-site HTML/CSS : pages HTML et CSS corrigées, mémento des commandes Linux, formulaire de contact, pages en construction.

**Site en ligne :** https://VOTRE-COMPTE.github.io/mini-site-ap2/

## Structure

```
index.html                     page d'accueil
pages/html.html                cours HTML
pages/css.html                 cours CSS
pages/linux_command_line.html  mémento des commandes Linux
pages/en_construction.html     page des sujets à venir
css/Global.css                 feuille de style commune (thème bleu foncé)
css/linux_command_line.css     style du tableau des commandes
js/main.js                     menu burger, animation des articles, formulaire
img/                           logos et icône
```

## Mise en ligne (GitHub Pages)

Settings > Pages > Source : *Deploy from a branch* > branche `main`, dossier `/ (root)`.

Note : le formulaire de contact affiche une confirmation de démonstration, car GitHub Pages n'exécute pas de PHP.
