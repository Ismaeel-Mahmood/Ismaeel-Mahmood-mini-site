Introduction à HTML

L'HTML a été créé par Tim Berners-Lee, un ingénieur britannique, en 1991. Il a développé cette technologie pour permettre aux chercheurs du monde entier de partager facilement des documents et des informations via Internet.

Tim Berners-Lee a conçu l'HTML dans le but de structurer et de présenter des informations sur le web. Il voulait créer un langage simple à utiliser, permettant de créer des pages web sans connaissances techniques approfondies, afin de faciliter la navigation, la mise en page et le partage d'informations.

HTML (HyperText Markup Language) est le langage utilisé pour créer des pages web. Il permet de structurer du contenu avec des balises et d'ajouter des attributs pour enrichir ces éléments.

Les balises HTML

Les balises HTML définissent la structure et le contenu d'une page web. Voici les plus courantes :

  • <h1> à <h6> : balises de titre
  • <p> : balise de paragraphe
  • <a> : balise de lien
  • <img> : balise d'image
  • <div> : balise de division

Attributs HTML

Les attributs sont des informations supplémentaires ajoutées aux balises pour modifier leur comportement ou leur apparence :

  • class : définit une classe CSS pour un élément
  • id : définit un identifiant unique pour un élément
  • src : indique la source d'une image ou d'un fichier multimédia
  • href : indique l'URL d'un lien

Exemple de code HTML

<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <title>Exemple de page HTML</title>
</head>
<body>
    <h1>Bienvenue sur ma page web</h1>
    <p>Ceci est un paragraphe d'exemple.</p>
    <a href="https://www.example.com">Visitez mon site</a>
</body>
</html>

Explication du code

  • <!DOCTYPE html> : indique au navigateur qu'il s'agit d'un document HTML5.
  • <head> : contient l'encodage (charset) et le titre de la page.
  • <body> : contient le contenu visible : un titre, un paragraphe et un lien.
