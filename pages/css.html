Introduction à CSS

CSS (Cascading Style Sheets) est un langage de style utilisé pour décrire la présentation d'un document HTML. Il permet de contrôler l'apparence visuelle des éléments d'une page web : couleurs, polices, marges et dispositions.

CSS a été développé par le W3C (World Wide Web Consortium) et publié pour la première fois en 1996. Il a évolué pour inclure des fonctionnalités avancées : animations, transitions et grilles.

CSS permet de séparer le contenu d'une page web de sa présentation, ce qui facilite la maintenance et la mise à jour des styles, et d'appliquer des styles cohérents sur l'ensemble d'un site.

Les éléments principaux du CSS

  • sélecteur : désigne les éléments à styliser (balise, .classe, #id)
  • propriété : caractéristique à modifier (color, margin, font-family)
  • valeur : la valeur donnée à la propriété (navy, 10px, Arial)
  • <link rel="stylesheet" href="..."> : lie un fichier CSS à une page HTML

Exemple de code CSS

h1 {
    color: navy;
    font-family: Georgia, serif;
}
.menu a {
    color: white;
    text-decoration: none;
}

Explication du code

  • h1 { ... } : le sélecteur h1 cible tous les titres de niveau 1.
  • color et font-family : changent la couleur et la police du titre.
  • .menu a : cible les liens placés dans un élément de classe « menu ».
